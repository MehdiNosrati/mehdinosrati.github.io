# Mahdi Nosrati Sahlan — Personal Portfolio

⚡ **Live at:** [mahdins.dev](https://mahdins.dev) | [mehdinosrati.github.io](https://mehdinosrati.github.io)

Ultra-modern, high-performance, dark cyber-luxe personal engineering portfolio designed and built with pure HTML5, modern CSS3, and vanilla ES6+ JavaScript.

---

## ✨ Features

- 🌌 **Interactive Constellation Canvas**: Real-time particle field with dynamic physics responding to mouse movements and gestures.
- 🔠 **Kinetic Decryption Text Effect**: Matrix/sci-fi style decoding animation for typography and role switcher.
- 🎴 **3D Tilt Holographic Cards**: Parallax hover perspective and specular lighting reflection on project and code cards.
- 💻 **Cyber Terminal Mode (CLI Easter Egg)**: Full-featured in-browser terminal emulator accessible via `⌘K` or the UI with interactive commands (`help`, `experience`, `projects`, `skills`, `contact`, `sudo hire`, `matrix`).
- ⚡ **Laser Timeline**: High-tech career timeline highlighting roles at **Google** (Google Play), **Yelp**, **Parsly Labs**, and **Hamsaa**.
- 🛠️ **Categorized Skills Matrix**: Interactive skill filter and constellation nodes.
- 📋 **One-Click Copy & Toast Alerts**: Instant email copy feedback and smooth rocket back-to-top navigation.
- 🚀 **Blazing Fast Performance**: Zero-dependency runtime, zero bundle bloat, responsive across all screen sizes.

---

## 🛠️ Tech Stack

- **Markup & Layout:** HTML5 Semantic Architecture
- **Styling:** Modern CSS3 (Custom Properties, Glassmorphism, CSS Grid & Flexbox, Keyframe Animations)
- **Engine & Graphics:** Vanilla JavaScript (ES6+), Canvas 2D API, Web Audio API
- **Deployment:** GitHub Pages & Custom Domain (`mahdins.dev`)

---

## 🚀 Local Development

To run locally without any dependencies:

```bash
# Python 3
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser.
